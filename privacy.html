Privacy Policy

Stryker Personal · last updated 26 October 2026

Stryker Personal is a single-user personal automation tool written and used by Ahmed Nimer. It is not a product, not offered to the public, and has no users other than its author.

What it accesses

With the account owner's explicit consent, the application requests read-only access to Gmail (gmail.readonly) and, separately, read access to Google Calendar. It can read messages and calendar entries. It cannot send, modify, or delete anything — the scopes granted do not permit it.

What it does with that data

  • Message and calendar data is read on demand, on the author's own computer, to summarize and organize his own information.
  • Nothing is transmitted to any third party, server, or analytics service.
  • Nothing is sold, shared, or used for advertising.
  • Nothing is used to train machine-learning models.

Storage and retention

OAuth tokens are stored locally on the author's own machine so the application does not have to re-authenticate on every run. Message content is processed in memory and is not retained in a database. Any local note or summary the author chooses to keep stays on his own machine.

Sharing

No data is shared with anyone. There are no third-party processors, no hosting provider receiving this data, and no other users of the application.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions. Doing so immediately stops all access. Locally stored tokens can be deleted by removing the application's token files.

Contact

Questions about this policy: the Google account that owns this application, as listed on the OAuth consent screen.
